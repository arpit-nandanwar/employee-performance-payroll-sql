# Employee Performance & Payroll Analysis (SQL)

## Overview
SQL queries to retrieve employee and payroll information and generate salary reports.

## SQL Concepts Used
- **Filtering & Sorting:** `SELECT`, `WHERE`, and `ORDER BY` to filter and sort employee records
- **Joins:** Combining employee and department data
- **Aggregations:** `GROUP BY` and aggregate functions to generate salary reports

## Key Analysis
- Retrieving and filtering employee and payroll records
- Sorting employee data using `ORDER BY`
- Joining employee and department data to generate salary reports

## Repository Files
- `schema.sql` — Database tables and foreign key relationships (`departments`, `employees`, `payroll_records`)
- `data.sql` — Sample records for departments, employees, and monthly payroll
- `queries.sql` — SQL queries for filtering, sorting, joins, and payroll/performance aggregations
